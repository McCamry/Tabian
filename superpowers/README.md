# SUPERPOWERS - สคริปต์และเครื่องมือพิเศษสำหรับระบบ Tabian

โฟลเดอร์นี้รวบรวมเครื่องมือ สคริปต์อัตโนมัติ และฟังก์ชันพิเศษสำหรับช่วยเหลือนักพัฒนาและผู้ดูแลระบบในการทดสอบ ประมวลผล และขยายขีดความสามารถของระบบ Tabian

---

## สคริปต์และเครื่องมือภายในโฟลเดอร์นี้

1. **`test-gemini-vision.ts`**:
   - สคริปต์ทดสอบการส่งรูปภาพป้ายทะเบียนไปยัง Google Gemini API เพื่อตรวจสอบผลการสกัดข้อมูลและทดสอบความแม่นยำ
2. **`seed-disaster-data.ts`**:
   - สคริปต์จำลองข้อมูลแผ่นป้ายทะเบียน 30+ รายการ สำหรับพื้นที่ประสบภัยน้ำท่วมจริง (เชียงใหม่, เชียงราย, พระนครศรีอยุธยา, สุโขทัย) ทั้งรถยนต์และมอเตอร์ไซค์
3. **`export-plates-csv.ts`**:
   - สคริปต์ส่งออกข้อมูลทะเบียนทั้งหมดเป็นไฟล์ CSV สำหรับส่งต่อให้ศูนย์บรรเทาสาธารณภัยหรือตำรวจภูธร
4. **`benchmark-plate-matching.ts`**:
   - สคริปต์ทดสอบความเร็วและประสิทธิภาพของระบบ Smart Matching ค้นหาและจับคู่ระหว่างฝั่ง "เจอ" และ "หา"
